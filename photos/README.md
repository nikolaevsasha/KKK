# Как добавить фотографии

Главный источник — файл `manifest.json` в этой папке: сайт читает его и показывает
- `gallery` — фото в слайдшоу (и они же показываются к кнопкам настроений, пока для настроений нет отдельных фото),
- `moods` — фото под конкретные настроения (`"sad": ["файл.jpg"]` и т.д.),
- `memes` — картинки, вылетающие при нажатии кнопок.

Добавил новые файлы — впиши их имена в `manifest.json` (или попроси Клода, он всё разложит).

Запасной вариант без манифеста: именованные файлы по схеме ниже подхватываются автоматически.

## Правила именования

**Галерея (слайдшоу внизу страницы):**
- `gallery1.jpg`, `gallery2.jpg`, `gallery3.jpg`, … (по порядку, без пропусков)

**Фото к кнопкам настроения** (показываются вместе с фразой):
- `sad1.jpg`, `sad2.jpg`, … — «Мне грустно»
- `tired1.jpg`, … — «Я устала»
- `angry1.jpg`, … — «Я злюсь»
- `miss1.jpg`, … — «Скучаю»
- `anxious1.jpg`, … — «Тревожно»
- `happy1.jpg`, … — «Мне хорошо»

**Мемы** (случайно вылетают поверх экрана при нажатии кнопок):
- `meme1.jpg`, `meme2.jpg`, … — любые ваши мемы/смешные картинки

Поддерживаются расширения: `.jpg`, `.jpeg`, `.png`, `.webp` (в нижнем регистре).

Важно: нумерация должна идти подряд с 1 — если есть `gallery1` и `gallery3`, но нет `gallery2`, сайт остановится на первом.

**Превью ссылки в мессенджерах:** загрузи сюда файл `og.jpg` (любое ваше фото, лучше горизонтальное ~1200×630) — оно будет показываться как картинка при отправке ссылки в Telegram/WhatsApp.
