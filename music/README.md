# Как добавить музыку

1. Загрузи аудиофайлы (.mp3, .m4a, .ogg) в эту папку через GitHub.
2. Впиши их в manifest.json в формате:

```json
[
  { "file": "track1.mp3", "title": "Звери — Районы-кварталы" },
  { "file": "track2.mp3", "title": "Наша песня" }
]
```

Или просто попроси Клода — он сам составит плейлист из загруженных файлов.

Плеер на сайте появляется автоматически, как только в manifest.json есть хотя бы один трек.

Важно: загружай только треки, на которые у тебя есть права (свои записи, купленные без DRM и т.п.).
